# personal-website
A personal website where I will deepen my software development skills, as well as display future personal projects for employers to see!

### project overview technical
**html+css** : website layout and design

**react** : routing allowing for the separate pages (home, "blog", about)

**service** : endpoints to call stored posts and display them when on the appropriate page

**database** : where posts will be stored

**websocket** : i'm not actually sure this is necessary for this project


### project overview
the home page will feature one post (most likely the latest, but may be the one I am most proud of). It will also include a pseudo-resume which employers can review. The "blog" page (although I want to come up with a different name) will include all posts. I am not sure yet if those posts will be purely computer science related or not, since my professor's website has many which are more "for fun." The about page will feature a picture of yours truly, as well as a brief bio, and perhaps a more complete resume.
